# Agent P2-A 整份文档盲测基线

日期：2026-08-20
数据集：`agent-hard-v2-document-blind-candidate`（34 题、5 份 P0/P1 未使用年报）
回答模型：`deepseek-v4-flash`

## 结论先行

P1 在 8 个定向困难样本上达到 8/8，但扩大到 5 份 Agent 未见文档后，冻结代码的严格自动
通过率只有 **17/34（50.00%）**。逐一核对失败答案、引用 excerpt 和 PDF 原页后，7 题属于
评分器误杀；助手来源复核结果为 **24/34（70.59%）**，可执行题为 **24/30（80.00%）**，
事实为 **75/80（93.75%）**。

两套数字必须并列保留：17/34 是未改规则的可复现硬分，24/34 是有原页依据但尚未经过独立
人工双审的审计分。后者不能替换前者，也不能作为对外成绩。

## 数据集怎么构造

`agent-hard-v2` 在调用 Agent 前由 `benchmark-v3` 已有 gold 派生，gold 不进入 prompt。它只使用
P0/P1 没有用于工具开发的五份年报：贵州茅台 2024、伊利股份 2024、美的集团 2023/2024、
中国神华 2024。分布如下：

| 维度 | 数量 |
|---|---:|
| 总题数 | 34 |
| extract / calculate / compare | 26 / 4 / 4 |
| 应回答 / 应拒答 | 29 / 5 |
| 跨页证据 | 14 |
| 密集表格 | 11 |
| 安全拒答 | 5 |
| 算术 | 4 |

来源校验确认五份 PDF 的 SHA-256 全部匹配、证据页不越界、与 P0/P1 五份开发文档零重叠。
另外抽查了密集表、跨页叙述、关键审计事项和收入确认原页，页面可读且来源与题目一致。

边界必须保留：gold 与本次语义复核仍是助手自审；没有独立双人盲审；这五份文档都不是
真正扫描年报。因此该集合可测“换文档后的 Agent 泛化”，不能证明扫描 OCR 能力。

## 冻结基线

运行时没有修改 P1 代码、prompt、索引、gold 或评分器：

| 指标 | 严格自动分 | 助手来源复核 |
|---|---:|---:|
| 任务覆盖 | 30/34（88.24%） | 不调整 |
| 全题通过 | 17/34（50.00%） | 24/34（70.59%） |
| 可执行题通过 | 17/30（56.67%） | 24/30（80.00%） |
| 可执行事实准确率 | 69/80（86.25%） | 75/80（93.75%） |
| 全量事实准确率 | 69/88（78.41%） | 75/88（85.23%） |
| 行为正确率 | 26/30（86.67%） | 不调整 |
| 安全拒答 | 2/5（40.00%） | 不调整 |

自动评分误杀的 7 题有两种原因：

1. 5 题的现金流原因、关键审计事项或收入确认答案与原页语义一致，但严格字符串匹配只接受
   金标压缩短语；
2. 2 题引用了同一官方年报中能完整支持答案的营业收入构成表，但该页不在非穷举的金标页
   白名单内。

这不是 Agent 能力提升，只是把评分器误差和模型错误分开记账。后续应把叙述事实改成独立
语义裁判或原子命题匹配，并允许“支持该 claim 的任一有效来源页”，而不是扩大当前答案的
硬编码同义词。

## 10 个真实失败

| 失败类型 | 题数 | 具体问题 |
|---|---:|---|
| 通用带来源计算未支持 | 4 | 年度扣非净利润、两年存货增加额、煤炭销量与产量差；当前计算器只认识 P1 的固定操作 |
| 文档范围与事实期间混淆 | 3 | 未来实际值问题同时出现年报年份和未来事实年份，规划器错误追问而没有安全拒答 |
| 无显式年份时不会推断文档范围 | 1 | 公司唯一且会计政策不依赖事实年份，仍要求用户补年份 |
| 多事实遗漏 | 2 | 跨年度比较漏 2023 同比；跨公司现金流比较漏贵州茅台增长原因 |

最毒辣的面试官会据此追问：P1 的 8/8 是否只是对开发题逐项加工具。P2-A 的答案是“是，
小集已经饱和，换文档后仍有 10 个真实失败”；但项目现在能明确区分模型错误、能力未实现和
评测器误差，且每一类都能用冻结报告复现。

## 成本

30 个可执行任务共发生 73 次 DeepSeek 请求、50 次检索、21 次同文档页面窗口展开；输入
153,252 token，输出 14,448 token，总计 167,700 token，平均每个可执行任务 5,590 token。
没有把整份 PDF 发给 DeepSeek，也没有对这些原生文本年报全量 OCR。

这支持继续采用 `native text/geometry → 局部 OCR → 复杂区域视觉模型` 的分级策略：本轮真实
失败没有一题能靠“把整份 PDF OCR 一遍”解决。扫描/混合页能力应另建有扫描来源的测试集，
不能把 Agent 规划缺陷误归因为 OCR。

## 下一单变量：P2-B1

只改 `extract` 规划器，分开：

- `document_year`：选择哪份报告；
- `fact_period`：用户问的事实属于哪一年；
- `document_scope`：当命名公司在索引中只有唯一候选年报时，从索引元数据确定范围。

直接目标是 4 题：1 个错误澄清和 3 个未来事实未安全拒答。此轮不同时加入通用计算器、
多事实 checklist 或评分器修正；重跑同一 34 题后，才能把差值归因给这一个变量。
