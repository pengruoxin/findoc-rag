hard-v3 已形成可执行的临时金标：96 道题覆盖 8 家公司、16 份官方年报，其中 80 道要求回答、8 道要求因当前语料缺失而拒答、8 道要求先澄清条件。

- 复杂表格、可比口径、关键审计事项和运力信息图已完成直接视觉复核。

- 标注和验证过程未调用 DeepSeek，也未运行被评测 Agent。
