## 每个增量解决了什么

1. **P0-A1**：只重试证据缺口；限制重复 target/query；预留最终提交预算。
2. **P0-A2**：证明 named `tool_choice` 单独使用没有增益。旧检索历史仍会诱导模型重复搜索。
3. **P0-A3**：最终提交使用只含任务、目标和 Evidence Memory 的新上下文，去掉陈旧工具历史。
4. **P0-B1**：target 显式区分 `fact_year`、`document_year`、`statement_scope`、
   `value_version`，规划准确率达到 100%。
5. **P0-B2**：为年报主要会计数据表和母公司附注生成结构定位词；同一张调整前/后表可绑定
   两个事实版本；跨报告比较不再把事实年份误当报告年份。
6. **P0-B3 / P0-B5**：保留为负结果。放宽模型侧提交 schema 会造成 answer 漏字段；仅增加
   非答案解析也不能解决模型错误选择 `answer` 的问题。
7. **P0-B6**：目标限定重试后仍为零证据时，本地门禁确定性 `abstain`，并明确禁止用预测、
   目标或外部知识补全；`validation_errors` 进入 trace。
8. **P0-B7 / P0-B8**：同比和重述任务建立同公司跨年度证据组；最终提交只补充已经检索到、
   同公司、同目标、指定报告年份的 provenance 引用。跨公司证据只在 claim 同时出现公司名
   与明确比较词时允许，普通事实 claim 仍保持严格目标绑定。

## 最终五个可执行难例

- 合并口径与母公司口径收入及差额：通过；
- 同一 2023 事实的 2024 年报调整前/后值及调整额：通过；
- 长江电力跨 2023/2024 报告的重述基数核对：通过；
- 两家公司 × 两年度四目标比较与同比结论：通过；
- 2025 实际收入未披露的安全拒答：通过。

剩余 3 题分别要求跨页表抽取/勾稽、章节状态跨页、以及图形连线关系重建。它们应进入下一
阶段的 `extract` / `calculate` / 页面窗口 / 结构化表格 / 视觉区域工具，不能继续扩写
`compare` prompt 来伪装任务覆盖提升。
