# Agent hard-v3 P0 通用带来源计算改进记录

## 结论

P0 已完成。原基线中 8 道 `calculate` 题均为 `unsupported_task_type`；改进后
calibration 4/4、dev 4/4 严格通过。组合后的 48 题机器严格通过率由
22/48（45.83%）提升至 30/48（62.50%），任务覆盖率由 83.33% 提升至 100%。

`frozen_test` 未打开，本记录仅覆盖 calibration 与 dev。

## 单变量范围

本轮只修改计算任务链路：

- 将增长率、占比、净利率、差额及多项求和路由到通用计算代理；
- 按指标和年报章节检索原始操作数；
- 要求 DeepSeek 为每个操作数提交证据 chunk，数值必须逐字存在于引用中；
- 使用本地 `Decimal` 执行公式，不接受模型心算结果；
- 非可比口径任务优先把年度操作数绑定到对应年度报告；
- 百分比相减由本地统一输出为“个百分点”。

未修改 PDF 解析、索引、普通抽取、比较代理、拒答逻辑、金标或评分规则。

4. 多事实长答案漏项及语义评分器误判。
